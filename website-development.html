COMMON QUESTIONS

Before you enquire

Can you improve an existing website?

Often, yes. We first review its platform, access arrangements and the changes you want before agreeing the scope.

Will my website work on mobile?

Responsive layouts are part of the proposed approach, with testing agreed for the project.

Can you guarantee first-page Google results?

No. We can build in sensible search-engine fundamentals, but no business can honestly guarantee a specific search ranking.
